Network

The radio's name on the LAN, and a USB Ethernet adapter: DHCP, or a fixed address for networks that need one. The same settings as Settings → Wireless on the radio. WiFi is not touched.

Any browser on the LAN reaches the radio as x6100.local (mDNS, announced by Avahi), on WiFi and Ethernet alike. The name is kept on the DATA partition.

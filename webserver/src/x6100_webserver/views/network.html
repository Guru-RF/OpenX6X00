Network

The radio's name on the LAN, the other names it answers to, and a USB Ethernet adapter: DHCP, or a fixed address for networks that need one. The same settings as Settings → Wireless on the radio. WiFi is not touched.

Network nameTakes effect: now, reachable under the new name in a few seconds

Any browser on the LAN reaches the radio as x6100.local (mDNS, announced by Avahi), on WiFi and Ethernet alike. The name is kept on the DATA partition.

Letters, digits and '-', up to 32

Other namesTakes effect: at once

These pages change settings and open the Files page, and the Panel, the Screen page and the Winlink mailbox connect, only when opened by one of the radio's own names: by any other name a page from another site could do the same through your browser. Its own names now: its address.

Names your own DNS or a reverse proxy gives the radio, separated by spaces, up to 8: whole names, not addresses (those count already), no wildcards. Only names of your own: a page opened by a name on this list can change everything here, so never add one a web site or a message asks for.

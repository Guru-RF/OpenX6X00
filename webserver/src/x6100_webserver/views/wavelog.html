Wavelog

Every QSO the radio logs, in every mode (FT8, FT4, FT2, JS8, voice, CW, Field Ops activations), goes to your Wavelog as well, a few seconds after it is logged; the radio's own logs stay as they are. Without a network the QSOs wait on the SD card and go when the radio is back online. The display says what happened: "Wavelog: DL1ABC uploaded".

UploadTakes effect: at the next QSO

Your Wavelog's address and a read & write API key: in Wavelog, your account menu, API Keys, Create a read & write key (it starts with wl; in Wavelog 3.1 and later under Legacy API Keys (API v1)). The API tokens further down that page, wl2_... (API v2), don't work here yet. The QSOs go into the station profile chosen here, or, with Automatic, into the profile with the callsign the radio logged them with. Switched on, the QSOs from that moment on are sent, not the log from before.

Wavelog follows the radio, and the radio follows a click in Wavelog. Both use the Wavelog URL and the read & write API key saved above, whether the upload is on or not; each is off until switched on here.

In split the frequency is where the radio transmits, and the RX frequency goes too. In Wavelog choose the radio in the radio list of the QSO page or the band map

The address you open Wavelog with in the browser, when it is not the Wavelog URL above (the radio reaches Wavelog by another name). Only Wavelog's page from there may tune the radio. Empty:

  • Wavelog opened over https (most are): the radio's address has to be https too, as a secure page may not call a plain http one. The radio's certificate is its own, not one a browser knows: open the radio's address once in the browser you use Wavelog in, accept the warning (Advanced, then Proceed), and the clicks work. The same for the Tailscale name, which serves the same certificate.
  • Wavelog opened over plain http (at home on a NAS): http and https both work. Wavelog tries the other one by itself when one fails.
  • The browser has to reach the radio: on the radio's own network, or from anywhere over Tailscale with Tailscale on that computer too. Automatic gives the radio's Tailscale name while Tailscale runs, else its address on the network; with Tailscale Funnel on, the Tailscale name's https is the Panel's, so then the address on the network.
  • Chrome and Edge may ask once whether Wavelog's site may reach devices on your local network: allow it, or the click does nothing.
  • After New address, or Tune from Wavelog off and on again, reload Wavelog's page: it keeps the address it read. Switched off here, Wavelog keeps the last address it got and the radio refuses it; Wavelog's Hardware Interfaces page (Edit) clears it there.

TCI server

TCI (Transceiver Control Interface, version 2.0) is the protocol of Expert Electronics' SDRs that AetherSDR and other programs serve: one WebSocket carries the frequency, mode, filter, AGC, PTT, the S-meter and the TX meters, and the audio both ways. The radio serves it here, so a VFO-Knob or any TCI client tunes it over the network, hears it and keys it. There is no login: enable it only on a network you trust.

Server

On ws://<radio IP>:<port>/ ; the radio applies changes within a few seconds

SSH

SSH on the radio takes keys only: password logins are off, since every radio came with the same root password. Add the public key of each computer you log in from; ssh root@x6100.local then logs in with it.

The public half: the one line of the .pub file

No key yet? On your computer, ssh-keygen -t ed25519 makes one; paste the line of ~/.ssh/id_ed25519.pub here (on Windows: type %USERPROFILE%\.ssh\id_ed25519.pub). Taken: ssh-ed25519, ecdsa-sha2-nistp256, -nistp384 and -nistp521, and ssh-rsa of 3072 bits or more, one key at a time, with no options before it.

Good to know

Where the keys are kept

  • The keys are root's, in /root/.ssh/authorized_keys. A copy goes to backups/backup.tgz on the DATA partition after each change here and at every clean power-off, so a new card image takes them back.
  • Removing a key does not end a session already open with it; the next login needs another key.
  • This page answers only to the radio's address or its own name (x6100.local): a page from another site cannot add a key through your browser.

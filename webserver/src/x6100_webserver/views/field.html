Field Ops

POTA, SOTA, WWBOTA, HOTA, WWFF, TOTA, WCA, MOTA, LH (lighthouses) and Tiles portable operation: reference lists for the radio, QRZ Logbook upload, HOTA and WWFF spots, activation logs.

QRZ LogbookTakes effect: at the next upload

Up to three profiles, a callsign with its Logbook API key (QRZ.com, Logbook, Settings): the active one takes the uploads. The radio's log page can switch the active profile too. Uploading needs a QRZ.com Logbook API key, which QRZ.com only gives with a paid QRZ.com subscription (XML level or higher).

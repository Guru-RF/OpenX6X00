# Themes (personal)

RS: RS-BA1 look cut from `rsba1.png`, a screenshot of Icom's RS-BA1. Personal use only: it
is not installed with the image (up to v0.3.5 it was). `python3 make_rs.py` rebuilds `RS/`;
copy `RS/` to the SD card as `/mnt/themes/RS/`. Format: [docs/THEMES.md](../docs/THEMES.md).
`zoom.py`, `lum.py`: helpers to inspect the screenshot.

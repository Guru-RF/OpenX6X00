# GhostNet's nets, as GhostNet version 1.5 has them (github.com/s2underground/GhostNet): the weekly net of each
# region (on Thursday evening there) and the data bridges between the regions on Saturday. Read by the JS8 app's
# GhostNet list and its reminders (src/ghostnet.c) and by the web page GhostNet (webserver ghostnet_web.py).
# A file of the same name on the DATA partition (/mnt/ghostnet_nets.txt) is read instead of this one: a newer
# GhostNet schedule without waiting for a firmware update.
#
#   net <id> <name>
#   <id> <day, UTC: Sun Mon Tue Wed Thu Fri Sat> <HH:MM UTC> <minutes> <kHz, - for none> <mode> <what>
#
# The reminder comes before the first JS8 window of each net; VARA and ALE windows need a PC, LSB is voice for
# emergencies only.
